**How to read the columns.**
- *what it PROVES* — one clause, taken from the file's own header, not from memory.
- *anchor* — where the rule or finding is recorded. "none in docs" means the finding lives ONLY in the script's header and must be written down before the script is archived.
- *unit test* — a test that holds the SAME claim (named), or "none". A test that merely mentions the probe's name is listed as such.
- *runs today?* — static classification for all; "sampled" rows were actually run (see the run table). "BROKEN as-is" means the file hardcodes a port and boots no server, so `node <path>` dies at `page.goto` with ECONNREFUSED unless a server is started by hand first — exactly the class the rot audit fixed for `.prove.mjs` files (`autoBase`), which it could not reach here because these are not `.prove.mjs` and are not wired.
- *last commit* — `2525298` (2026-08-30) is the repo's initial import (1,160 files); it is the last touch on 118 of 151 files, which means "no history in this repo", not "written that day".
- *rec* — **KEEP** guards a live invariant no unit test reaches · **CONVERT** the claim fits a ~100ms unit test (the assertion is named) · **ARCHIVE** one-shot; findings recorded at the anchor, or the rationale says where to record them · **BROKEN** cannot run and the reason is structural · **TOOL** not a probe (generator, server, library, release helper) — counted separately so the probe numbers stay honest. **KEEP·dark** = a KEEP whose surface is the default-OFF `?waveVideo` (see decision 2).
