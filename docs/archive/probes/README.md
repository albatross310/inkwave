# Retired probe scripts — the pre-move census and where each claim lives now

Moved here from `scripts/` on 2026-09-16 (branch `claude/refactor-probe-archive`), following
`docs/PROBE-TRIAGE.md` (PR #6, the 2026-09-15 census — every row below is its `rec` column) and
decision 1's order: (a) the four header-only findings were written into the named archive sections,
(b) the nine CONVERT rows landed as unit tests (47 tests, 15 mutants die), (c) then these files moved.
The directory structure under `scripts/` is preserved one level down, so an old pointer
`scripts/<sub>/<file>` resolves to `docs/archive/probes/<sub>/<file>`.

**These files are not run by anything.** They are kept as the record of HOW each number was
measured — the harness, the traps, the known-negatives — not as guards. Most hardcode a port and
boot no server (the rot audit reached only `.prove.mjs`), several read fixtures outside the repo, and
the `scrub-probe/` family string-slices its own siblings (`probe.mjs`, `probe-thumbs.mjs`) — which is
why that family moved WHOLE. `scripts/scrub-probe/server.mjs` (a TOOL, used by other probes) stayed.

**Count:** 71 `.mjs` files / 7869 lines (62 ARCHIVE + 9 CONVERT), plus `scrub-probe/README.md`.
The triage's ARCHIVE bucket was 63 / 7,019; one row was reclassified and stays under `scripts/`:
`textrender-probe/zoom.prove.mjs` — it is the named instrument of the OPEN decision 3 (does the
live editor still owe canonical breaks at zoom≠1 after `8f5ae9d`?) and prints the divergence Peter has
to rule on; retiring it before the ruling would remove the only thing that shows the question.
